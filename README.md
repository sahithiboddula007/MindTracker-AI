# MindTracker-AI 🧠
An AI-powered Mental Health Tracking System developed to monitor mood, wellness and provide intelligent chatbot support.

## ✨ Features
- Daily Mood Tracking & Analytics
- AI Chatbot for Mental Wellness
- Secure SQLite Database
- Interactive Flask Web App

## 🚀 Tech Stack
Python | Flask | SQLite | AI/ML

## ▶️ How to Run
pip install -r requirements.txt
python app.py
